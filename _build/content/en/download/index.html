RoastLink for Windows — a single executable, no installer required.

Current version: Beta (free)
Requires a Windows PC with Bluetooth support. This isn't an installer — just download the .exe and run it directly.

Download latest version

Windows may show a "Windows protected your PC" warning when you run it. This is normal and expected -- it appears because the app isn't signed with a paid code-signing certificate, not because it's malware. Click More info, then Run anyway.
The download includes an Artisan settings file (.aset) alongside the exe. Loading it into Artisan applies every step of the Setup Guide (1 through 6) at once -- just double-check the port number matches what's shown in the app window.

Before you start

  • Windows 10/11 with Bluetooth
  • A Sandbox Smart R1 roaster
  • Artisan (roasting software) — if you don't have it yet, get it at artisan-scope.org

First time setting this up? Follow the Setup Guide in order.
