Frequently Asked Questions

I moved only one slider, but burner, air, and drum all moved together.

Artisan's "Quantifiers" setting is turned on. Follow Step 6 of the setup guide to disable it.

No temperature shows up on screen at all.

Check that Input 1/2's Node (BT/ET) and Mode (C) aren't empty in Artisan's WebSocket settings — see Step 2: Port.

I dropped, but cooling doesn't kick in — the fan doesn't get louder.

First press "Stop Cooling" in RoastLink, then slowly press OFF → START → DROP in Artisan, 3 seconds apart. If that still doesn't work, the safest option is to power the roaster off and back on directly.

A "Connection was lost" popup appeared.

RoastLink couldn't confirm a response from the roaster. Check that Bluetooth is on and the roaster is powered on. If needed, restart the roaster and reconnect.

The Sampling dialog has no field to enter a command.

That's normal. RoastLink refreshes the temperature automatically, so no command needs to be entered in this dialog.

What port number should I use?

Use exactly the port number shown in the RoastLink window (default 8080).
