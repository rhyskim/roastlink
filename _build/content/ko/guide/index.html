설정 가이드

아래 순서대로 Artisan을 설정하면 RoastLink와 정상적으로 연동됩니다. 순서가 중요하니 하나씩 차례로 진행해주세요.

아래 표에 나온 명령어 값들은 직접 타이핑하지 않아도 됩니다. RoastLink 프로그램을 실행한 뒤 "Artisan 설정 가이드 열기" 버튼을 누르면, 3~5단계에서 필요한 값들을 각 항목 옆의 [복사] 버튼으로 그대로 복사해 Artisan에 붙여넣을 수 있습니다. (포트 번호처럼 짧은 숫자 값은 복사 버튼 없이 화면에 표시된 그대로 눈으로 보고 입력하시면 됩니다.)

1단계 장치 설정

Artisan에게 "온도를 어디서 받아올지" 알려주는 단계입니다.

  1. Artisan 메뉴에서 설정 → 온도센서 설정(단축키 Ctrl+D)을 엽니다. (Artisan 버전에 따라 "장치"로 표시될 수도 있습니다.)
  2. Meter를 WebSocket으로 설정합니다.
  3. 오른쪽 Curves에서 ET, BT를 모두 체크합니다.
  4. LCDs에서도 ET, BT를 모두 체크합니다.
이 창의 이름은 Artisan 버전/언어에 따라 다를 수 있습니다 — 핵심은 Meter를 WebSocket으로 맞추는 것입니다.

2단계 포트 설정

RoastLink가 실행 중인 위치(포트)를 Artisan에게 알려주는 단계입니다.

  1. Artisan 메뉴에서 설정 → 시리얼 포트 설정 → WebSocket 탭을 엽니다. (Network 탭이 아니라 반드시 WebSocket 탭입니다.)
  2. Host: localhost
  3. Port: RoastLink 프로그램 화면에 표시된 포트 번호(기본값 8080)
  4. Data Request: getData
  5. Input 1의 Node: BT, Input 2의 Node: ET
  6. 두 Input의 Mode: C (섭씨)
중요: "Messages" 항목의 CHARGE / DROP 입력칸은 반드시 비워두세요. 여기에 값이 남아있으면(예: 예전 설정의 잔여값) 배출 시 냉각이 제대로 걸리지 않을 수 있습니다.

3단계 샘플링

온도를 얼마나 자주 확인할지 정하는 간단한 단계입니다.

  1. Artisan 메뉴에서 설정 → 견본 추출(Sampling)을 엽니다.
  2. 주기를 2.00 secs로 설정합니다.
  3. Keep ON을 체크합니다.
  4. 확인을 누릅니다.
이 창에 명령을 입력하는 칸이 따로 없어도 정상입니다. RoastLink가 필요할 때 온도를 자동으로 갱신하므로, 이 창에서는 주기와 Keep ON만 설정하면 충분합니다.

4단계 이벤트 버튼

예열 시작, 투입, 배출 같은 동작 버튼을 연결하는 단계입니다.

  1. Artisan 메뉴에서 설정 → 이벤트 → 설정(Config) 탭을 엽니다.
  2. 아래 5개 버튼 각각의 WebSocket Command 칸에 표에 적힌 값을 그대로 입력합니다.
버튼WebSocket Command
START (예열 시작)send({ "pushMessage": "PREHEAT" })
CHARGE (투입)send({ "pushMessage": "HSTART" })
DROP (배출)send({ "pushMessage": "DROP" })
OFF (꺼짐)send({ "pushMessage": "OFF" })
COOL END (냉각 종료)send({ "pushMessage": "COOLING_STOP" })
여기 적힌 값들은 로스터기에 직접 보내는 명령이 아니라, RoastLink가 이해하고 안전한 순서로 변환해서 처리하는 신호입니다. 표에 있는 그대로 입력하시면 됩니다.

5단계 슬라이더

화력·공기·드럼을 조절하는 슬라이더를 연결하는 단계입니다.

  1. Artisan 메뉴에서 설정 → 이벤트 → 슬라이더(Sliders) 탭을 엽니다.
  2. 아래 표대로 각 슬라이더의 WebSocket Command, 최저/최고, 눈금 간격(Step)을 입력합니다.
슬라이더WebSocket Command최저~최고눈금간격
Air (공기)send({{ "pushMessage": "DRAW {}" }})0 ~ 1005
Drum (드럼)send({{ "pushMessage": "DRUM {}" }})0 ~ 1005
Burner (화력)send({{ "pushMessage": "HEAT {}" }})0 ~ 1005
눈금 간격(Step)은 반드시 5로 설정하세요. 1로 설정하면 슬라이더를 살짝만 움직여도 명령이 훨씬 더 많이, 빠르게 전송돼 로스터기와의 통신이 불안정해질 수 있습니다.

6단계 구간표시들(Quantifiers) 끄기 필수

이 단계를 건너뛰면 슬라이더 하나만 움직여도 화력·공기·드럼이 전부 같은 값으로 튀는 심각한 문제가 발생합니다. 반드시 확인해주세요.
  1. Artisan 메뉴에서 설정 → 이벤트 → 사용자콘트롤(Quantifiers) 탭을 엽니다. (5단계에서 연 창과 같은 창의 다른 탭입니다.)
  2. 공기(Air), 드럼(Drum), 버너(Burner) 세 줄 모두, 맨 왼쪽 이벤트 체크박스를 전부 해제합니다.
  3. 적용 → 확인으로 저장합니다.
  4. 창을 다시 열어 체크가 실제로 풀린 채 유지되는지 한 번 더 확인합니다.
이 설정은 원래 "온도값을 슬라이더에 자동으로 반영"해주는 기능인데, 이 로스터기와는 맞지 않아 반드시 꺼야 합니다. [설정] 탭에서 "구간표시들" 체크박스 하나만 끄는 것으로는 해결되지 않습니다 — 반드시 이 [사용자콘트롤] 탭 안에서 이벤트별로 꺼야 합니다.

로스팅 실전 절차

설정이 모두 끝났다면, 실제 로스팅은 이런 순서로 진행하시면 됩니다.

  1. RoastLink 실행 → 로스터기 검색 → 연결
  2. RoastLink 설정 패널에서 예열 목표 온도 확인/조정
  3. Artisan에서 ON(웹소켓 연결) — 온도가 화면에 뜨는지 확인
  4. START(예열 시작) 클릭 — 목표 온도에 도달하면 RoastLink가 화면 알림 + 소리로 알려드립니다
  5. CHARGE(투입) — 원두를 넣고 클릭하면 화력·공기·드럼 슬라이더가 실제로 동작하기 시작합니다
  6. 로스팅 진행하며 슬라이더로 화력/공기/드럼 조절, 1차크랙 등은 Artisan의 이벤트 마킹 기능으로 기록
  7. DROP(배출) — 냉각이 시작되었다는 팝업이 뜹니다. 10초 안에 팬 소리가 커지는지 확인하세요
  8. 냉각이 끝나면 자동으로 정지되거나, COOL END를 눌러 마무리
  9. 로스팅 기록은 Artisan 자체 그래프/저장 기능으로 조회·저장
배출 후 10초가 지나도 팬 소리가 안 커진다면, RoastLink 화면의 "쿨링 정지"를 누른 뒤 Artisan에서 OFF → START → DROP을 3초 간격으로 천천히 다시 눌러보세요. 자주 묻는 질문에 더 자세한 대처법이 있습니다.
