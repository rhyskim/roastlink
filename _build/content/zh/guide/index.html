设置指南

请按以下顺序设置 Artisan，才能与 RoastLink 正常连接。顺序很重要，请依次完成每一步。

下面表格里的命令值不需要手动输入。 打开 RoastLink 程序后点击 "打开 Artisan 设置指南" 按钮，第3~5步需要的每一个值旁边都有 [复制] 按钮，点一下就能直接粘贴到 Artisan 里。（像端口号这种 较短的数字没有复制按钮，照屏幕上显示的输入即可。）

第1步 设备设置

这一步是告诉 Artisan 从哪里获取温度数据。

  1. 在 Artisan 中打开 Config → Device（快捷键 Ctrl+D）。 （根据 Artisan 版本，名称可能略有不同。）
  2. 将 Meter 设置为 WebSocket。
  3. 在 Curves 中勾选 ET 和 BT。
  4. 在 LCDs 中同样勾选 ET 和 BT。
此对话框的名称可能因 Artisan 版本/语言而异 — 关键是把 Meter 设置为 WebSocket。

第2步 端口设置

这一步是告诉 Artisan RoastLink 正在运行的位置（端口）。

  1. 在 Artisan 中打开 Config → Port → WebSocket 标签页。 （不是 Network 标签页，必须是 WebSocket 标签页。）
  2. Host：localhost
  3. Port：RoastLink 窗口中显示的端口号（默认 8080）
  4. Data Request：getData
  5. Input 1 的 Node：BT，Input 2 的 Node：ET
  6. 两个 Input 的 Mode：C（摄氏度）
重要："Messages" 中的 CHARGE / DROP 输入框必须留空。 如果这里残留了旧的设置值，下豆时冷却可能无法正常启动。

第3步 采样

设置多久检查一次温度，这一步很简单。

  1. 在 Artisan 中打开 Config → Sampling。
  2. 将间隔设置为 2.00 secs。
  3. 勾选 Keep ON。
  4. 点击确定。
这个对话框没有输入命令的地方是正常的。RoastLink 会在需要时自动刷新温度，所以 这一步只需设置间隔和 Keep ON 即可。

第4步 事件按钮

这一步设置开始预热、投豆、下豆等操作按钮。

  1. 在 Artisan 中打开 Config → Events → Config 标签页。
  2. 将下表中的值依次填入下面 5 个按钮各自的 WebSocket Command 输入框。
按钮WebSocket Command
START（开始预热）send({ "pushMessage": "PREHEAT" })
CHARGE（投豆）send({ "pushMessage": "HSTART" })
DROP（下豆）send({ "pushMessage": "DROP" })
OFF（关闭）send({ "pushMessage": "OFF" })
COOL END（冷却结束）send({ "pushMessage": "COOLING_STOP" })
这些值并不是直接发送给烘焙机的命令，而是 RoastLink 能够识别、并按安全顺序转换 处理的信号。请按表中内容原样填写。

第5步 滑块

这一步设置控制火力、风门、滚筒的滑块。

  1. 在 Artisan 中打开 Config → Events → Sliders 标签页。
  2. 按下表填写每个滑块的 WebSocket Command、最小/最大值和步进（Step）。
滑块WebSocket Command最小～最大步进
Air（风门）send({{ "pushMessage": "DRAW {}" }})0 ~ 1005
Drum（滚筒）send({{ "pushMessage": "DRUM {}" }})0 ~ 1005
Burner（火力）send({{ "pushMessage": "HEAT {}" }})0 ~ 1005
步进（Step）必须设置为 5。如果设置为 1，即使滑块只移动一点点， 也会更频繁、更快速地发送命令，可能导致与烘焙机的通信不稳定。

第6步 关闭量化器（Quantifiers） 必须

跳过这一步会导致严重问题：只移动一个滑块，火力、风门、滚筒会全部跳到 相同的数值。请务必完成这一步。
  1. 在 Artisan 中打开 Config → Events → Quantifiers 标签页 （与第5步是同一个对话框中的另一个标签页）。
  2. 将 Air、Drum、Burner 三行最左侧的事件复选框 全部取消勾选。
  3. 点击 Apply，然后 OK 保存。
  4. 重新打开该对话框，确认复选框确实保持未勾选状态。
这个功能原本用于"根据温度自动驱动滑块"，但并不适合这台烘焙机，必须关闭。 仅在 Config 标签页取消勾选一个"Quantifiers"复选框是不够的 — 必须在这个 [Quantifiers] 标签页中逐项关闭。

烘焙实操流程

设置全部完成后，实际烘焙请按以下顺序进行。

  1. 启动 RoastLink → 搜索烘焙机 → 连接
  2. 在 RoastLink 设置面板中确认/调整预热目标温度
  3. 在 Artisan 中点击 ON（连接 WebSocket）— 确认温度已显示在 界面上
  4. 点击 START（开始预热）— 达到目标温度时，RoastLink 会通过 弹窗和声音提醒您
  5. 点击 CHARGE（投豆）— 放入咖啡豆后点击，火力/风门/滚筒滑块 开始真正生效
  6. 烘焙过程中用滑块调节火力/风门/滚筒，一爆等事件用 Artisan 自带的事件标记功能记录
  7. 点击 DROP（下豆）— 会弹出冷却已开始的提示。请在 10 秒内 确认风扇声音是否变大
  8. 冷却结束后会自动停止，或点击 COOL END 手动结束
  9. 烘焙记录可通过 Artisan 自带的图表/保存功能查看和保存
如果下豆 10 秒后风扇声音仍未变大，请先在 RoastLink 中点击"Stop Cooling（停止 冷却）"，然后在 Artisan 中按 OFF → START → DROP 的顺序、每隔 3 秒缓慢地重新点击一次。更多处理方法请参见常见问题。
