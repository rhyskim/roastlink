Setup Guide

Follow these steps in Artisan, in order, to connect it to RoastLink. The order matters, so please go through them one at a time.

You don't have to type the command values below by hand. Launch RoastLink and click the "Open Artisan Setup Guide" button — every value needed for Steps 3–5 has a [Copy] button next to it, so you can paste it straight into Artisan. (Short numeric values like the port number have no copy button — just read them off the screen and type them in.)

Step 1 Device

This step tells Artisan where its temperature readings come from.

  1. In Artisan, open Config → Device (shortcut Ctrl+D). (Depending on your Artisan version, this may be labeled differently.)
  2. Set Meter to WebSocket.
  3. Under Curves, check both ET and BT.
  4. Under LCDs, check both ET and BT as well.
This dialog's exact name can vary by Artisan version/language — the key thing is setting Meter to WebSocket.

Step 2 Port

This step tells Artisan where RoastLink is running.

  1. In Artisan, open Config → Port → WebSocket tab. (Not the Network tab — it must be the WebSocket tab.)
  2. Host: localhost
  3. Port: the port number shown in the RoastLink window (default 8080)
  4. Data Request: getData
  5. Input 1 Node: BT, Input 2 Node: ET
  6. Mode for both inputs: C (Celsius)
Important: under "Messages", the CHARGE / DROP fields must be left empty. A leftover value here (e.g. from an old config) can prevent cooling from actually starting when you drop.

Step 3 Sampling

A quick step to decide how often Artisan checks the temperature.

  1. In Artisan, open Config → Sampling.
  2. Set the interval to 2.00 secs.
  3. Check Keep ON.
  4. Click OK.
It's normal for this dialog to have no command field. RoastLink refreshes the temperature on its own whenever needed, so setting the interval and Keep ON here is all this step requires.

Step 4 Event Buttons

This step wires up the buttons for starting preheat, charging, and dropping.

  1. In Artisan, open Config → Events → Config tab.
  2. For each of the 5 buttons below, paste the value from the table into its WebSocket Command field.
ButtonWebSocket Command
START (begin preheat)send({ "pushMessage": "PREHEAT" })
CHARGEsend({ "pushMessage": "HSTART" })
DROPsend({ "pushMessage": "DROP" })
OFFsend({ "pushMessage": "OFF" })
COOL ENDsend({ "pushMessage": "COOLING_STOP" })
These values aren't sent directly to the roaster — RoastLink understands them and translates them into the correct, safe sequence internally. Just paste them exactly as shown.

Step 5 Sliders

This step wires up the sliders that control burner, air, and drum.

  1. In Artisan, open Config → Events → Sliders tab.
  2. For each slider below, enter its WebSocket Command, min/max, and step exactly as shown.
SliderWebSocket CommandMin–MaxStep
Airsend({{ "pushMessage": "DRAW {}" }})0 – 1005
Drumsend({{ "pushMessage": "DRUM {}" }})0 – 1005
Burnersend({{ "pushMessage": "HEAT {}" }})0 – 1005
Step must be set to 5. Setting it to 1 means even a small slider movement sends far more commands, much faster, which can make the connection to the roaster unstable.

Step 6 Disable Quantifiers Required

Skipping this step causes a serious problem: moving just one slider makes burner, air, and drum all jump to the same value. Please don't skip it.
  1. In Artisan, open the Config → Events → Quantifiers tab (a tab in the same dialog you opened in Step 5).
  2. For all three rows — Air, Drum, Burner — uncheck the leftmost event checkbox completely.
  3. Apply, then OK to save.
  4. Reopen the dialog once to confirm the checkboxes stayed unchecked.
This feature is meant to auto-drive a slider from a temperature reading, which doesn't suit this roaster and must be turned off. Unchecking the single "Quantifiers" checkbox on the Config tab is not enough — you must disable each event individually here, on the Quantifiers tab.

Roasting Walkthrough

Once setup is done, here's the actual sequence for a real roast.

  1. Launch RoastLink → scan for your roaster → connect
  2. Check/adjust the preheat target temperature in RoastLink's settings panel
  3. Turn Artisan ON (WebSocket connects) — confirm temperature appears on screen
  4. Click START (begin preheat) — when the target is reached, RoastLink shows an on-screen alert and plays a sound
  5. Click CHARGE — load the beans; the burner/air/drum sliders now actually take effect
  6. During the roast, adjust burner/air/drum with the sliders; mark first crack etc. using Artisan's own event-marking feature
  7. Click DROP — a popup confirms cooling has started. Check within 10 seconds that the fan actually sounds louder
  8. Cooling stops automatically when finished, or click COOL END to finish manually
  9. View/save your roast record using Artisan's own graph/save features
If the fan doesn't sound louder within 10 seconds of dropping, press "Stop Cooling" in RoastLink, then slowly press OFF → START → DROP in Artisan, 3 seconds apart. See the FAQ for more detail.
