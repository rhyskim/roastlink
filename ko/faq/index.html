자주 묻는 질문

슬라이더 하나만 움직였는데 화력·공기·드럼이 전부 같이 움직여요.

Artisan의 "사용자콘트롤(Quantifiers)" 설정이 켜져 있기 때문입니다. 설정 가이드 6단계를 따라 꺼주세요.

온도가 화면에 전혀 표시되지 않아요.

Artisan의 웹소켓 설정에서 Input 1/2의 Node(BT/ET)와 Mode(C)가 비어있지 않은지 확인하세요 — 2단계: 포트 설정을 참고하세요.

배출했는데 쿨링(냉각)이 안 걸려요. 팬 소리가 안 커집니다.

먼저 RoastLink 화면의 "쿨링 정지" 버튼을 누른 뒤, Artisan에서 OFF → START → DROP을 3초 간격으로 천천히 다시 눌러보세요. 그래도 안 되면 로스터기 전원을 직접 껐다 켜는 것이 가장 안전합니다.

"연결이 끊어졌습니다" 팝업이 떴어요.

RoastLink가 로스터기로부터 응답을 확인하지 못했다는 뜻입니다. 블루투스가 켜져 있는지, 로스터기 전원이 켜져 있는지 확인해주세요. 필요하면 로스터기를 재시작한 뒤 다시 연결해보세요.

샘플링 설정 창에 명령을 입력하는 칸이 없어요.

정상입니다. RoastLink가 온도를 자동으로 갱신하기 때문에, 이 창에는 별도의 명령을 입력할 필요가 없습니다.

포트 번호를 뭘로 입력해야 하나요?

RoastLink 프로그램 화면에 표시된 포트 번호를 그대로 입력하세요(기본값 8080).

예열이나 로스팅 중에 실수로 "쿨링 정지" 버튼을 눌렀는데, 오히려 냉각이 시작돼요.

로스터기 자체의 특성 때문에, 예열이나 로스팅이 진행 중인 상태에서 "쿨링 정지"를 누르면 오히려 냉각이 시작됩니다. 정상적인 사용 흐름(배출 → 냉각 → 필요시 쿨링 정지)에서는 겪을 일이 없는 상황이니 걱정하지 않으셔도 됩니다. 혹시 실수로 이렇게 됐다면, 이제 냉각이 실제로 진행 중이므로 "쿨링 정지"를 한 번 더 누르면 정상적으로 멈춥니다.
